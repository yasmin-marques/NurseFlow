# NurseFlow

Sistema de gerenciamento de escalas de enfermagem desenvolvido para auxiliar na organização dos plantões hospitalares.

O NurseFlow tem como objetivo automatizar o processo de criação, gerenciamento e acompanhamento das escalas de enfermeiros, considerando disponibilidade dos profissionais, setores e regras de distribuição de plantões.

## Funcionalidades

- Cadastro e gerenciamento de enfermeiros;
- Controle de disponibilidade e restrições de horários;
- Gerenciamento de setores hospitalares;
- Criação e edição de escalas;
- Visualização de escalas e plantões;
- Solicitação e gerenciamento de trocas de plantão;
- Controle de acesso por perfil de usuário.

## Banco de Dados

O projeto utiliza MongoDB como banco de dados, contendo collections para gerenciamento de:

- Usuários;
- Enfermeiros;
- Administradores;
- Disponibilidades;
- Escalas;
- Plantões;
- Setores;
- Trocas de plantão.
